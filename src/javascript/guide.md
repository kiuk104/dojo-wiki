## .js는 자바가 아니에요 {#js-vs-java}

> 🏷️ `javascript` `기초` · 📅 2026-10-21

**한 줄 요약:** `.js` = **자바스크립트(JavaScript)**. 자바(Java)와는 완전히 다른 언어.

### 비교
| | 자바스크립트 | 자바 |
|---|---|---|
| 확장자 | `.js` | `.java` |
| 주로 쓰는 곳 | 웹, 크롬 확장, 웹앱 | 안드로이드, 서버, 기업용 |
| 실행 | 브라우저 / `node 파일.js` | 컴파일 후 실행 |

### 코딩Dojo 예제가 .js인 이유
1. 1장 원본 프로젝트(`notebooklm-podcast-extension`)가 순수 자바스크립트
2. 코딩Dojo 채점 엔진이 자바스크립트를 실행 → 연습한 코드를 그대로 붙여넣어도 동작
3. Fokus 시리즈, 코딩Dojo 같은 웹앱이 모두 자바스크립트 기반

### 실행 준비 확인
```powershell
node -v
```

`v20.x.x` 같은 숫자가 나오면 OK. 안 나오면 nodejs.org 에서 Node.js 설치.

## 링크를 이미 열린 창에서 열기 (target 이름) {#link-target}

> 🏷️ `html` `링크` `pwa` · 📅 2026-10-22

**한 줄 요약:** `target="_blank"` 는 매번 새 탭, `target="이름"` 은 **그 이름의 창이 있으면 다시 쓴다.**

### 문제 / 상황
코딩Dojo의 "📖 위키에서 더 보기"를 누를 때마다 위키 탭이 하나씩 늘어났다.

### 해결
```html
<!-- 전: 누를 때마다 새 탭 -->
<a href="https://kiuk104.github.io/dojo-wiki/..." target="_blank">

<!-- 후: "dojo-wiki" 라는 이름의 창을 다시 씀 -->
<a href="https://kiuk104.github.io/dojo-wiki/..." target="dojo-wiki">
```

위키 쪽(`shared/core.js`)도 열릴 때 스스로 이름표를 단다.

```js
window.name = 'dojo-wiki';
```

설치한 위키 앱(PWA)은 `manifest.webmanifest` 에 아래를 넣어서, 새 창 대신 **이미 열린 앱 창**으로 가게 했다.

```json
"launch_handler": { "client_mode": ["navigate-existing", "auto"] }
```

### 왜 그런가
창 이름은 **Blender 오브젝트 이름**과 비슷하다. 같은 이름의 오브젝트가 있으면 새로 만들지 않고 그걸 찾아 쓴다. `_blank` 는 "이름 없음 = 늘 새로 만들기"라는 특별한 값이다.

> ⚠️ 주의: 브라우저는 보안 때문에 **내가 직접 따로 연 탭**의 이름은 다른 사이트에서 못 찾는 경우가 많다(크롬). 그래서 처음 한 번은 새 탭이 열리고, 그다음부터 그 탭이 계속 다시 쓰인다.

> 💡 꿀팁: 크롬에 위키를 앱으로 설치했다면, 앱 창 메뉴(⋮) → **앱 정보 / 설정** → **"지원되는 링크 열기"** 를 켜면 브라우저에서 누른 위키 링크가 위키 앱 창으로 열린다.

## 문자열 속 역슬래시는 두 번 (`\\`) {#backslash-escape}

> 🏷️ `javascript` `문자열` `이스케이프` `윈도우경로` · 📅 2026-10-22

**한 줄 요약:** JS 문자열 안에서 `\`는 "다음 글자는 특수 기호야"라는 신호라서, 진짜 `\` 한 개를 쓰려면 `\\` 두 개를 쓴다.

### 문제 / 상황
윈도우 경로 `C:\flutter\bin` 을 JS 문자열에 그대로 넣으면 경로가 깨진다.
```js
'C:\flutter\bin'    // \f = 페이지넘김, \b = 백스페이스 문자로 바뀜 → 경로가 망가짐
```

### 해결
```js
'$env:Path += ";C:\\flutter\\bin"'   // 실제 값: $env:Path += ";C:\flutter\bin"
```
화면에 적는 건 `\\` 두 개, 실제로 들어가는 건 `\` 한 개.

### 왜 그런가
문자열 안의 `\`는 **이스케이프 문자** — 바로 뒤 글자와 짝을 지어 특별한 뜻이 된다.

| 적는 것 | 실제 뜻 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\'` | 따옴표 글자 (문자열이 안 끝남) |
| `\\` | 역슬래시 글자 한 개 |

3D 노드에서 "이 값은 숫자가 아니라 텍스처 경로야"라고 **입력 타입을 표시**하는 것처럼, `\`는 "다음 글자를 평소처럼 읽지 마"라는 표시. 그래서 `\` 자체를 쓰고 싶으면 표시를 한 번 더 붙여 `\\`.

- **주석(`//`)과 터미널**에는 한 개만 쓴다 — 문자열이 아니니까.
- `console.log('C:\\flutter\\bin')` 으로 찍어 보면 `C:\flutter\bin` 이 나온다.

> 💡 꿀팁: 경로는 `/` 로 써도 윈도우가 대부분 알아듣는다 → `'C:/flutter/bin'` (두 번 쓸 필요 없음)

### 관련
- PATH — 프로그램을 찾아보는 폴더 목록
