## .js는 자바가 아니에요 {#js-vs-java}

> 🏷️ `javascript` `기초` · 📅 2026-10-21

**한 줄 요약:** `.js` = **자바스크립트(JavaScript)**. 자바(Java)와는 완전히 다른 언어.

### 비교
| | 자바스크립트 | 자바 |
|---|---|---|
| 확장자 | `.js` | `.java` |
| 주로 쓰는 곳 | 웹, 크롬 확장, 웹앱 | 안드로이드, 서버, 기업용 |
| 실행 | 브라우저 / `node 파일.js` | 컴파일 후 실행 |

### 코딩Dojo 예제가 .js인 이유
1. 1장 원본 프로젝트(`notebooklm-podcast-extension`)가 순수 자바스크립트
2. 코딩Dojo 채점 엔진이 자바스크립트를 실행 → 연습한 코드를 그대로 붙여넣어도 동작
3. Fokus 시리즈, 코딩Dojo 같은 웹앱이 모두 자바스크립트 기반

### 실행 준비 확인
```powershell
node -v
```

`v20.x.x` 같은 숫자가 나오면 OK. 안 나오면 nodejs.org 에서 Node.js 설치.

## 링크를 이미 열린 창에서 열기 (target 이름) {#link-target}

> 🏷️ `html` `링크` `pwa` · 📅 2026-10-22

**한 줄 요약:** `target="_blank"` 는 매번 새 탭, `target="이름"` 은 **그 이름의 창이 있으면 다시 쓴다.**

### 문제 / 상황
코딩Dojo의 "📖 위키에서 더 보기"를 누를 때마다 위키 탭이 하나씩 늘어났다.

### 해결
```html
<!-- 전: 누를 때마다 새 탭 -->
<a href="https://kiuk104.github.io/dojo-wiki/..." target="_blank">

<!-- 후: "dojo-wiki" 라는 이름의 창을 다시 씀 -->
<a href="https://kiuk104.github.io/dojo-wiki/..." target="dojo-wiki">
```

위키 쪽(`shared/core.js`)도 열릴 때 스스로 이름표를 단다.

```js
window.name = 'dojo-wiki';
```

설치한 위키 앱(PWA)은 `manifest.webmanifest` 에 아래를 넣어서, 새 창 대신 **이미 열린 앱 창**으로 가게 했다.

```json
"launch_handler": { "client_mode": ["navigate-existing", "auto"] }
```

### 왜 그런가
창 이름은 **Blender 오브젝트 이름**과 비슷하다. 같은 이름의 오브젝트가 있으면 새로 만들지 않고 그걸 찾아 쓴다. `_blank` 는 "이름 없음 = 늘 새로 만들기"라는 특별한 값이다.

> ⚠️ 주의: 브라우저는 보안 때문에 **내가 직접 따로 연 탭**의 이름은 다른 사이트에서 못 찾는 경우가 많다(크롬). 그래서 처음 한 번은 새 탭이 열리고, 그다음부터 그 탭이 계속 다시 쓰인다.

> 💡 꿀팁: 크롬에 위키를 앱으로 설치했다면, 앱 창 메뉴(⋮) → **앱 정보 / 설정** → **"지원되는 링크 열기"** 를 켜면 브라우저에서 누른 위키 링크가 위키 앱 창으로 열린다.

## 문자열 속 역슬래시는 두 번 (`\\`) {#backslash-escape}

> 🏷️ `javascript` `문자열` `이스케이프` `윈도우경로` · 📅 2026-10-22

**한 줄 요약:** JS 문자열 안에서 `\`는 "다음 글자는 특수 기호야"라는 신호라서, 진짜 `\` 한 개를 쓰려면 `\\` 두 개를 쓴다.

### 문제 / 상황
윈도우 경로 `C:\flutter\bin` 을 JS 문자열에 그대로 넣으면 경로가 깨진다.
```js
'C:\flutter\bin'    // \f = 페이지넘김, \b = 백스페이스 문자로 바뀜 → 경로가 망가짐
```

### 해결
```js
'$env:Path += ";C:\\flutter\\bin"'   // 실제 값: $env:Path += ";C:\flutter\bin"
```
화면에 적는 건 `\\` 두 개, 실제로 들어가는 건 `\` 한 개.

### 왜 그런가
문자열 안의 `\`는 **이스케이프 문자** — 바로 뒤 글자와 짝을 지어 특별한 뜻이 된다.

| 적는 것 | 실제 뜻 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\'` | 따옴표 글자 (문자열이 안 끝남) |
| `\\` | 역슬래시 글자 한 개 |

3D 노드에서 "이 값은 숫자가 아니라 텍스처 경로야"라고 **입력 타입을 표시**하는 것처럼, `\`는 "다음 글자를 평소처럼 읽지 마"라는 표시. 그래서 `\` 자체를 쓰고 싶으면 표시를 한 번 더 붙여 `\\`.

- **주석(`//`)과 터미널**에는 한 개만 쓴다 — 문자열이 아니니까.
- `console.log('C:\\flutter\\bin')` 으로 찍어 보면 `C:\flutter\bin` 이 나온다.

> 💡 꿀팁: 경로는 `/` 로 써도 윈도우가 대부분 알아듣는다 → `'C:/flutter/bin'` (두 번 쓸 필요 없음)

### 관련
- PATH — 프로그램을 찾아보는 폴더 목록

## 슬래시 `/` 와 역슬래시 `\` 구분 {#slash-vs-backslash}

> 🏷️ `경로` `URL` `윈도우` `문자열` · 📅 2026-10-22

**한 줄 요약:** 인터넷·코드 세상은 `/`, 윈도우 탐색기만 `\`. 헷갈리면 `/` 를 쓰면 거의 다 통한다.

### 생김새
| 기호 | 이름 | 모양 기억법 |
|---|---|---|
| `/` | 슬래시 | 오른쪽으로 **앞으로** 기운 사람 (forward slash) |
| `\` | 역슬래시 (백슬래시) | **뒤로** 기댄 사람 (back slash). 한글 키보드에선 `₩` 로 보이기도 함 (같은 키) |

### 어디에 뭘 쓰나
| 상황 | 기호 | 예 |
|---|---|---|
| 윈도우 경로 (탐색기·PowerShell) | `\` | `E:\Coding\dojo-wiki` |
| 웹 주소 (URL) | `/` | `https://kiuk104.github.io/dojo-wiki/` |
| Mac·리눅스 경로, git, import | `/` | `./chapters/chapter0.js` |
| JS 주석 | `//` | `// 메모` |
| JS 나눗셈 | `/` | `10 / 2` |
| JS 문자열 속 특수문자 | `\` | `\n`(줄바꿈), `\\`(역슬래시 글자) |

### 💡 헷갈릴 땐 `/`
윈도우도 경로에 `/` 를 대부분 알아듣는다.
```powershell
cd E:/Coding/dojo-wiki      # 됨
```
```js
'C:/flutter/bin'            // \\ 두 번 쓸 필요 없음
```

### 왜 둘로 나뉘었나
옛날 DOS 가 `/` 를 명령 옵션 표시(`dir /w`)로 먼저 써 버려서, 폴더 구분에는 남은 `\` 를 썼다. 나머지 세상(유닉스·인터넷)은 처음부터 `/`. 3D 툴마다 Y-up / Z-up 이 갈린 것과 비슷한 "역사적 사정".

> ⚠️ 주의: JS 문자열 안의 `\` 는 경로 구분자가 아니라 **특수 신호**다 → "문자열 속 역슬래시는 두 번" 페이지.

### 관련
- 문자열 속 역슬래시는 두 번
- PATH — 프로그램을 찾아보는 폴더 목록


## CSS 변수 이름이 겹치면 색이 사라져요 {#css-var-name-clash}

> 🏷️ `css` `변수` `다크모드` · 📅 2026-11-11

**한 줄 요약:** `--ko` 처럼 이미 쓰는 CSS 변수 이름을 다른 뜻(글자 크기)으로 또 쓰면, 그 안쪽에서는 **원래 값(색)이 덮어써져** 사라진다. 용도가 다르면 이름도 다르게(`--ko-size`).

### 문제 / 상황
Fokus Podcast 에 "틀어놓기" 화면을 만들면서 한국어 해석을 초록색(`--ko`)으로 칠했는데, 라이트·다크 둘 다 **회색**으로 나왔다. 테스트는 "해석 색 ≠ 팁 색"만 확인해서 통과해 버렸고, 스크린샷을 눈으로 보고서야 알았다.

```css
:root   { --ko: #1d8a5b; }              /* style.css: 한국어 = 초록 */
.ls-sub { --ko: 2.4vw; }                /* 내가 추가: 글자 크기로 또 씀 ✗ */
.ls-ko  { color: var(--ko); font-size: var(--ko); }  /* color: 2.4vw → 무효 → 물려받은 회색 */
```

### 해결
```css
.ls-sub { --ko-size: 2.4vw; }
.ls-ko  { color: var(--ko); font-size: var(--ko-size); }
```
테스트도 "다르다" 대신 **정확한 값**을 비교하게 바꿨다: 라이트 `rgb(29, 138, 91)`, 다크 `rgb(79, 207, 149)`.

### 왜 그런가
CSS 변수는 **Blender 의 오브젝트 커스텀 속성**처럼 부모 → 자식으로 물려 내려간다. 중간 오브젝트(`.ls-sub`)에서 같은 이름에 새 값을 넣으면, 그 아래 자식들은 모두 새 값만 본다. `color` 에 `2.4vw` 같은 길이가 들어가면 브라우저는 그 줄을 버리고 부모 글자색을 그대로 쓴다 — 오류 메시지도 없이.

> ⚠️ 주의: "A 와 B 가 다르다"는 테스트는 둘 다 틀려도 통과할 수 있다. 색·크기처럼 정답이 정해진 값은 **정확한 값**으로 확인하자.

> 💡 꿀팁: 변수 이름에 용도를 붙이면 안 겹친다 — 색은 `--ko`, 크기는 `--ko-size`, 간격은 `--ko-gap`.

### 관련
- 계산과 화면을 나누면 테스트가 쉬워요

## 계산과 화면을 나누면 테스트가 쉬워요 {#split-logic-from-ui}

> 🏷️ `javascript` `테스트` `node` · 📅 2026-11-11

**한 줄 요약:** "어디로 이동할지 · 무엇을 보여 줄지" 정하는 **계산**을 화면 코드와 다른 파일로 빼면, 브라우저 없이 `node --test` 로 1초 만에 검사할 수 있다.

### 문제 / 상황
틀어놓기 화면은 "같은 문장 묶음을 3번 반복", "독일어만 듣기(해석 건너뛰기)" 같은 규칙이 있다. 이걸 화면 코드 안에 섞어 두면, 확인하려고 매번 MP3 를 틀고 몇 분씩 들어야 한다.

### 해결
1) 계산만 하는 파일 `listen-logic.js` — 화면(`document`)도 소리(`Audio`)도 안 만진다.
```js
// 위치(초)를 받아서 "여기로 옮겨" 또는 null 을 돌려줄 뿐
onTick(pos) { ... return target; }
```
2) 브라우저와 Node 둘 다에서 읽히게 끝을 이렇게:
```js
if (typeof module === "object" && module.exports) module.exports = api;  // Node 테스트
else window.ListenLogic = api;                                          // 브라우저
```
3) 테스트는 "가짜 재생기"로: 0.1초씩 앞으로 가면서 `onTick` 이 옮기라는 곳으로 점프.
```js
for (let pos = 0; pos < end; pos += 0.1) {
  const target = s.onTick(pos);
  if (target != null) pos = target;
}
```
```powershell
node --test tests\listen_logic.test.js
```
같은 규칙을 쓰는 Flutter 앱(Fokus Player)의 테스트와 **같은 시간표·같은 질문**으로 만들어서, 두 앱이 똑같이 동작하는지도 확인했다.

### 왜 그런가
3D 로 치면 **리깅(뼈대 계산)과 렌더링을 분리**하는 것과 같다. 뼈가 제대로 굽는지는 렌더 안 걸고 뷰포트에서 바로 본다. 계산이 맞는 걸 확인한 뒤에야 화면(렌더)을 따로 확인하면 된다 — 화면은 헤드리스 크롬(Playwright)으로 클릭·키보드를 흉내 내서 검사했다.

> 💡 꿀팁: 테스트가 정말 쓸모 있는지 보려면 코드를 **일부러 망가뜨려** 보자(조건 하나를 `true` 로 바꾸기 등). 그래도 테스트가 다 통과하면 그 부분은 아무도 지켜보지 않는 것 — 테스트를 하나 더 붙인다.

### 관련
- CSS 변수 이름이 겹치면 색이 사라져요
